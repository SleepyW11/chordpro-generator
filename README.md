# ChordPro Generator

A application built with **Angular** to generate guitar chord sheets that can be written with **[ChordPro](https://www.chordpro.org/)** DSL.

## Features

- Code Editor used - **[Monaco Editor](https://microsoft.github.io/monaco-editor/)** by Microsoft.
- Icons provided by **[Ionicons](https://ionicons.com/)**.

### Deployed App - [ChordPro Generator](https://sleepyw11.github.io/chordpro-generator/)
